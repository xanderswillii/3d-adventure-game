# Goblin Slayer
A 3D action-adventure game built in odot 4, featuring first-person and third-person exploration, sword combat, senemy, and portal-basedd travel between worlds

# Features
- First-person/ thrid person camera switch: to tohhhle view
- Sword Combat: atack with cooldown-based timing and a matching swing animation and sound
- Enemy: enemies cycle through idle, chase, attack, and die states, using NavigationAgen3D for pathfinding and detection areas
- portal-based World travel: step trhough a portalto transititon between seperate world scenes.
- HP and gold systems: tracks player health and currency, displayed live on the HUD
- persistent background music

  # Controls
- move: WASD
- look around: Mouse
- Jump: space bar
- attack: F
- switch Camera view: V
- Quit: Escape
